## Findings to resolve before release scoring

1. **Signed, currency-prefixed money is rejected.** `test_credit_note_negative_prefixed_currency_survives_cli` passes a grounded raw `-$11.95` from the literal PDF text through the actual vision adapter, domain assembly and CLI persistence. The exported observation preserves the raw string but records `value: null`, `state: ambiguous` and reason `not a number`. The expected amount is `-11.95` and the unresolved currency is a separate reading. `split_currency` in `src/vision_tables/domain/units.py` looks for a leading currency prefix before consuming the sign, so common credit-note totals cannot normalize in this form.
2. **A discarded page can still be reported as fully processed.** `test_cli_flags_unassembled_page_in_a_mixed_type_group` supplies two conflicting document classifications for an explicit pair of pages. The actual assembler records `page_doc_type_mismatch` and discards the second page's records. The CLI nevertheless exits 0 and stores `processed_pages: [1,2]`, `incomplete_pages: []`. The existing review issue is visible, but coverage and exit status imply a complete assembly. Mark the omitted page incomplete while retaining the fact that it was read.
3. **Three synthetic expectations use incompatible canonical values or codes.** `test_synthetic_labels_use_canonical_unit_and_crossout_flag` verifies the domain emits `l` for written `L`, and `crossed_out` is a boolean. The French pack label uses `L`, while the recipe places the string `1 tsp` in the flag slot. Use canonical `l` and `crossed_out: true`. Use the quantity and replacement-quantity fields to score the old and new amounts where evidenced. `test_cli_evaluation_scores_production_token_limit` demonstrates that a bounded reply produces `incomplete_pages: [1]` and `model_token_limit`; the label currently requires `output_truncated`, so the scorer reports a false miss. These are reference-contract corrections and require updated label hashes.
4. **Missing yield and recipe metric scope need a declared scoring convention.** The extractor prompt omits absent fields. The domain reports `recipe_yield_missing` when no yield observation exists. The synthetic and archival recipe labels require a `not_present` observation, so an otherwise correct absence reported by a domain issue counts as a miss. If both encodings satisfy the intended contract, require the issue when accepting an omitted observation and score fabricated yields as failures. The synthetic recipe currently counts two time/temperature fields per variant in the quantity/unit/yield metric. Keep their exact field checks and report recipe time and temperature separately if using the business metric name as documented.

The real-data manifests use earlier catalogue descriptions and human transcriptions. The local checks verified provenance entries and content addresses. Sparse anchors select exact readable names and can measure a labeled name and price or quantity pairing, while these fixtures do not measure complete row recall, row order or coverage of unlabeled facts. All held-out real examples are historical and tagged English. Jefferson's scan is low-resolution, the NYPL development transcription is marked under review and the archive sources are small enough that a single row affects the reported fractions materially.
