# Interface proposal for independent audit

The package is src/vision_tables on Python 3.12. Pydantic v2 objects forbid extra fields. Contracts live in contracts.py. The integrator owns settings, pipeline.py, model provisioning, JSON Schema export, locks and migration ordering. Paths passed between stages refer to local artifacts under an explicit working directory. Input strings from a document never become paths, queries, URLs or commands.

Use one source per job, immutable bytes SHA256. A logical document is a stable hash of source digest and ordered page scope; configuration and schema changes make a new extraction version, independent of output location. Separate UUID job id. Default scope is one page per document when multiple pages cannot be reliably grouped. Explicit ordered page groups permit continuation.

Source records digest, media type, bytes, page count. Page records original 1-based page number, original dimensions and unit (px or PDF points), path to rendered image, render dimensions and six-coefficient image-to-original affine. Region records stable id, page, text, reading order, layout class, writing style and optional grounded page-space box. Ingested contains source/pages/regions, issues and skipped pages. Runtime returns PageReading with page, classified doc type, ordered records of entity kind, local row id, parent link, field name => a reading containing original text/value, alternatives, reading state, evidence and optional grounded region id. Semantics are bounded by allowed entity and field names, and validated again after inference. No generated coordinates in the direct route.

Canonical document stores source and ordered pages/regions, run metadata, entities with parent_id, observations with per-entity field, raw/normalized value, reading state, origin, evidence refs, alternatives, and derivation with input observation ids. Normalized scalar values are strings (including finite decimal strings), flags or null. Corrections append to history and create a new immutable version. Validation, capture coverage and human approval are independent. Every result starts in review. No automatic acceptance at launch. Export from the same frozen snapshot.

Planned functions (see frozen signatures after review): vision.inspect_source and vision.read_page; domain.assemble and domain.revalidate; pipeline.extract(path, output, settings) -> one or more documents; store saves jobs, versions and materialized relational data; evaluate.run(manifest, output, settings). CLI owns dispatch and explicit error exits. Settings include route, type, page groups, page/pixel/byte/token/crop/retry budgets, state/model paths. Only content-affecting settings form the config fingerprint.
