# Initial contract freeze

The lead accepts the independent audit of e55f50e. The normative interface is the committed contracts.py, vocabulary.py, wire_json.py and interfaces.md with these decisions. Source inventory and working stages may proceed independently while network provisioning continues. Production release gates require real inference.

1. Only ModelPayload (or a smaller adapter-specific strict grammar projected into it) accepts model text. Read with wire_json.parse_object before validation. Adapter validates supplied region IDs, forbids model geometry and telemetry, saves raw attempts, and sets incomplete on a token-limit finish regardless of JSON validity. Rereads retain conflicting candidates with evidence and yield null unresolved values. Max model calls per page = 1 + retries + max_crops; hybrid adds one layout/recognition pass with bounded regions. All heavy calls take the shared absolute flock. Separate source pixels, rendered pixels, and grounded crop extents with their transforms.
2. For explicit grouping, all ungrouped processed pages still produce singleton documents. Every known page is recorded in ingestion.json. Retain skipped members of an explicit group in its identity. Record source_skipped_pages on all documents. Incomplete status overrides the summary validation string; issue codes still expose domain check outcomes. Suspected capture sets both compatibility flags and an issue. All reads need review, including clean photographs. Failure with no fields yields a nonzero terminal job and local attempt evidence.
3. The observed field vocabulary is shared. A printed and calculated total have separate field names. Typed entity containment expresses ordered row/choice/variant relationships. An optional bundle_choice.item_ref identifies a separately evidenced existing menu item. Domain must check kind/parent, numeric and flag semantics, ambiguous source spelling and review rules. Unsupported or ungrounded model output yields rejection or a review issue. No auto-approval.
4. Base extraction keys are unique on (document_id, run.config_hash); snapshot keys on (document_id, version). Link every corrected/reprocessed child to its prior version. Reimport returns reviewed descendant of that base; errors without usable data never reserve its success key. Correction canonical payload digest identifies repeat operations. Check replay before stale-version rejection, atomically. Empty changes may explicitly approve a valid result. Reject direct edits to derivations and rerun calculations after each human edit. Keep immutable prior observations and run provenance through version history.
5. The extractor owns normalization and policy tests, the persistence engineer owns durable history and transaction tests, the vision engineer owns attempt, geometry and truncation tests. JSON Schema and the canonical validation graph are checked at assembly/persistence. The independent integrated review determines whether implementation satisfies the frozen design.
